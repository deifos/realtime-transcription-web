This is demo of realtime transcription using Moonshine web powered by TransformersJS and NextJS 15.

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

Install dependencies:

```bash
npm install
```

### Web Mode

Run the Next.js development server in the browser:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Desktop Mode (Tauri)

Run as a native desktop app using Tauri. Requires [Rust](https://rustup.rs/) to be installed.

```bash
npx tauri dev
```

The first build will take several minutes to compile Rust dependencies. Subsequent builds are much faster.
